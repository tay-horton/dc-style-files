# DC Style Files — WEB 110 Local Guide Starter

This is a three-page, responsive website starter for a Washington, DC fashion-lover's local guide.

## Pages
- `index.html` — Home and introduction
- `streetwear.html` — Streetwear and sneakers (Joint Custody, Delorean 88, Sister Skateshop)
- `vintage.html` — Vintage and boutiques (Vintage Vintage Vintage, Sourced by Scottie, Secondi)
- `css/style.css` — Shared stylesheet
- `images/` — Folder for photos or other images you add in later modules

## GitHub setup
1. Create a **public** GitHub repository named `dc-style-files`.
2. On the repository page, click **Add file → Upload files**.
3. Upload the **contents** of this folder (not the zip file). Keep the CSS folder intact.
4. Commit changes and copy the repository URL into your discussion post.
5. Open `index.html` in your browser to check the links. You can optionally publish through GitHub Pages by selecting **Settings → Pages → Deploy from a branch**.
