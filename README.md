# DC Style Files — Final Local Guide

A three-page Washington, DC fashion guide for visitors interested in independent shops, streetwear, sneakers and vintage clothing. Built for WEB 110, Fall 2026.

## Pages
- `index.html` — Home
- `streetwear.html` — Streetwear & Sneakers
- `vintage.html` — Vintage & Boutiques

## Design
External CSS, Flexbox navigation, CSS Grid layouts, responsive media queries, semantic HTML, descriptive links, image alternative text and visible keyboard focus. Shop title graphics are local SVG illustrations (not photographs of actual shops), prepared with ChatGPT assistance. Shop links provide current visitor information.

Module 12 accessibility notes are retained in `MODULE_12_ACCESSIBILITY_AUDIT.md` as a historical record.
